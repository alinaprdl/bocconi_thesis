# bocconi_thesis
Master's thesis (Bocconi MiM) on gendered leadership language in executive search firm publications. Examines agentic vs. communal trait framing across a 10-year corpus from five leading ESFs (Korn Ferry, Egon Zehnder, Heidrick &amp; Struggles, Russell Reynolds, Spencer Stuart) using human coding + LLM classification. Supervisor: Prof. Francioli.
